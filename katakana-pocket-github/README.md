# カタカナ ポケット

ひらがなを見て、カタカナを指書きするスマホ向けウェブアプリです。
サーバー・APIキー・ビルド作業は不要です。

## パソコンで試す
ZIPを展開して index.html をブラウザで開いてください。
スマホへの配布は、GitHub Pagesなどの静的ホスティングをご利用ください。

## GitHubへアップする
1. GitHubで新しいリポジトリを作ります。
2. このZIPを展開します。
3. 展開した中身（index.html、style.css、app.js、i18n.js、certificate.js、README.md）を、リポジトリの一番上へアップロードします。ZIPそのものではなく、中身をアップロードしてください。
4. リポジトリの Settings → Pages で、公開元を Deploy from a branch、ブランチを main、フォルダを / (root) にして保存します。別のブランチ名を使う場合はそのブランチを選んでください。
5. 公開が完了するとPagesにURLが表示されます。そのURLを生徒に配ってください。

## 機能
- 名前を入力してから開始。その回の修了証の名前は固定
- 重複なしのランダム10問／あいうえお順46問
- あ〜んの基本文字のみ。濁音・半濁音・小書き文字なし
- 通常はお手本なし。ヒントを押したときだけ表示
- 日本語／タイ語／英語
- 部門別の名前入り修了証とPNG画像の保存
- クリア履歴と言語設定を端末のブラウザ内に保存

## 判定と記録
文字の形をフォントと比較する簡易判定です。書き順は判定しません。
端末や筆跡によって誤判定する場合があります。
修了証はブラウザ内で生成します。本人確認や改ざん検証の機能はありません。
名前・修了記録をサーバーに送る機能はありません。
ブラウザを閉じたり再読込すると、その回の途中経過と修了証は失われます。修了証は画面を閉じる前に保存してください。

## ファイル
- index.html：画面
- style.css：見た目
- app.js：ゲーム・名前固定・修了証表示
- i18n.js：3言語の文章
- certificate.js：修了証のPNG保存

この配布版にはSitesのログイン機能や公開設定は含まれていません。
GitHub Pagesで公開すれば、サイト自体にChatGPTへのログインは不要です。
