# Kana Pocket — ひらがな・カタカナ

入口は `index.html`、ひらがな版は `hiragana-pocket/`、既存のカタカナ版は `katakana-pocket-github/` です。
すべて静的ファイルで、ビルドやAPIキーは不要です。GitHub Pagesの公開元に中身をそのまま配置できます。

- タイ語が初期表示。日本語・英語にも切替可能
- ひらがな：ローマ字とタイ語の発音目安から指書き。ヒントはひらがな表示
- カタカナ：ひらがなから指書き。既存URLを維持
- 両方ともランダム10問、46文字順、行別20問、名前固定の修了証、PNG保存
- 文字の形を比較する簡易判定です。書き順は判定しません
- 名前と修了証は端末内で処理し、クリア記録は文字種別に分けてブラウザ内に保存
- 再読込で進行中の問題と修了証は失われます。修了証を閉じる前に画像で保存してください

## 読み上げ
ひらがな版の音声ボタンは Web Speech API を使い、端末にある日本語音声を選びます。
日本語音声がない場合は画面に案内を表示します。音声の品質や対応は端末・ブラウザにより異なります。
「を」は通常の発音として「お」を読み上げます。「ん」は単独音のため読み方が不自然になる場合があります。
タイ語表記は発音の目安で、正確な発音記号ではありません。
後から録音へ差し替える場合は `hiragana-pocket/readings.js` の音声ボタン処理を変更します。
